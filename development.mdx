## System overview

AgriSense AI is built on a modern, scalable architecture that combines mobile computing with cloud-based AI services to deliver real-time crop disease detection and advisory.

## Core components

<AccordionGroup>
  <Accordion title="Mobile application (Android/ADK)" icon="mobile">
    The native Android application serves as the primary user interface:
    
    - **Camera integration**: Captures high-quality images of crop leaves
    - **Image preprocessing**: Optimizes images before sending to Vertex AI
    - **Local caching**: Stores disease data and recommendations for offline access
    - **Multi-language support**: Swahili and English localization
    - **Location services**: Finds nearby agro-vet shops
    
    Built with Android Development Kit (ADK) for optimal performance and native features.
  </Accordion>

  <Accordion title="Vertex AI Vision" icon="brain">
    Google Cloud's Vertex AI provides the disease detection capabilities:
    
    - **Image classification**: Trained on African crop disease datasets
    - **Disease identification**: Recognizes common crop diseases from leaf images
    - **Confidence scoring**: Provides accuracy metrics for each detection
    - **Model versioning**: Supports continuous model improvements
    
    The model is trained on datasets specific to African crops and environmental conditions.
  </Accordion>

  <Accordion title="Google Genkit" icon="message-bot">
    Genkit generates contextual recommendations and advisory content:
    
    - **Treatment recommendations**: Provides step-by-step treatment instructions
    - **Prevention strategies**: Suggests preventive measures for detected diseases
    - **Localized content**: Uses African agricultural best practices
    - **Natural language**: Generates human-readable advice in multiple languages
    
    Powered by agricultural knowledge bases specific to East African farming practices.
  </Accordion>

  <Accordion title="Local storage & offline mode" icon="database">
    SQLite database enables offline functionality:
    
    - **Disease database**: Cached information about common crop diseases
    - **Recommendation cache**: Stores previously generated advice
    - **Image history**: Maintains user's detection history
    - **Sync mechanism**: Updates cache when connectivity is available
    
    Ensures farmers can use the app even in areas with poor internet connectivity.
  </Accordion>
</AccordionGroup>

## Data flow

<Steps>
  <Step title="Image capture">
    User captures a photo of a crop leaf using the mobile app camera
  </Step>
  <Step title="Preprocessing">
    App optimizes the image (resize, compress, format) for API transmission
  </Step>
  <Step title="Disease detection">
    Image is sent to Vertex AI Vision API for classification and disease identification
  </Step>
  <Step title="Result processing">
    App receives disease detection results with confidence scores
  </Step>
  <Step title="Advisory generation">
    Disease information is sent to Genkit to generate treatment recommendations
  </Step>
  <Step title="Display & cache">
    Results and recommendations are displayed to the user and cached locally
  </Step>
</Steps>

## Technology stack

### Mobile layer
- **Language**: Kotlin
- **Framework**: Android Development Kit (ADK)
- **UI**: Material Design 3
- **Camera**: CameraX API
- **Storage**: SQLite with Room persistence library

### AI/ML layer
- **Vision AI**: Google Cloud Vertex AI
- **Model type**: Image classification (CNN-based)
- **Advisory**: Google Genkit
- **Training data**: African crop disease datasets

### Infrastructure
- **Cloud platform**: Google Cloud Platform
- **Authentication**: Firebase Authentication
- **Analytics**: Firebase Analytics
- **Crash reporting**: Firebase Crashlytics

## Scalability

The architecture is designed for horizontal scalability:

- **Regional deployment**: Can be deployed across multiple African regions
- **Model training**: New disease models can be trained for different crops and regions
- **Language expansion**: Additional languages can be added through Genkit
- **API scaling**: Cloud infrastructure auto-scales based on demand

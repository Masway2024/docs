## Prerequisites

Before you begin, ensure you have:

- Android Studio installed (latest version)
- Android SDK 24 or higher
- Google Cloud account with Vertex AI enabled
- Basic knowledge of Android development

## Set up in three steps

Get AgriSense AI running on your device and start detecting crop diseases.

### Step 1: Set up your development environment

<AccordionGroup>
  <Accordion icon="copy" title="Clone the repository">
    Clone the AgriSense AI repository to your local machine:
    
    ```bash
    git clone https://github.com/your-org/agrisense-ai.git
    cd agrisense-ai
    ```
  </Accordion>
  <Accordion icon="cloud" title="Configure Google Cloud">
    1. Create a new project in [Google Cloud Console](https://console.cloud.google.com)
    2. Enable Vertex AI API
    3. Create a service account and download the JSON key
    4. Place the key file in `app/src/main/assets/credentials.json`
    
    <Warning>Keep your credentials file secure and never commit it to version control.</Warning>
  </Accordion>
  <Accordion icon="android" title="Set up Android Studio">
    1. Open Android Studio
    2. Select "Open an existing project"
    3. Navigate to the cloned repository
    4. Wait for Gradle sync to complete
    
    <Tip>Android Studio will automatically download required dependencies.</Tip>
  </Accordion>
</AccordionGroup>

### Step 2: Configure the application

<AccordionGroup>
  <Accordion icon="gear" title="Update configuration">
    Open `app/src/main/res/values/config.xml` and update:

    ```xml
    <resources>
        <string name="vertex_ai_project_id">your-project-id</string>
        <string name="vertex_ai_location">us-central1</string>
        <string name="genkit_api_key">your-genkit-key</string>
    </resources>
    ```
  </Accordion>
  <Accordion icon="database" title="Initialize local database">
    The app uses local caching for offline mode. Run the database initialization:

    ```bash
    ./gradlew initDatabase
    ```
    
    This creates the SQLite database for storing disease information and recommendations.
  </Accordion>
</AccordionGroup>

### Step 3: Build and run

<Accordion icon="rocket" title="Launch the app">
  1. Connect your Android device or start an emulator
  2. Click the "Run" button in Android Studio
  3. Select your target device
  4. Wait for the app to build and install
  
  <Tip>Use a physical device for testing camera functionality.</Tip>
</Accordion>

## Test the application

Once the app is running, test the core functionality:

<Steps>
  <Step title="Grant permissions">
    Allow camera and storage permissions when prompted
  </Step>
  <Step title="Capture an image">
    Tap the camera button and take a photo of a crop leaf
  </Step>
  <Step title="View results">
    Wait for AI analysis and view the disease detection results
  </Step>
  <Step title="Get recommendations">
    Review the treatment recommendations generated by Genkit
  </Step>
</Steps>
